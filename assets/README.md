# assets/ — 동요·효과음 음원

봇이 실제로 트는 소리 파일. **git 미추적**(용량 — mp3 한 곡이 2~4MB).
목록과 별칭은 `configs/audio_assets.yaml` 에 있고 그쪽은 git 에 들어간다.

```
assets/
├── songs/    동요 (mp3/ogg/wav — soundfile 0.14 가 mp3 도 그대로 읽는다)
└── sounds/   동물 효과음 (wav, 1~2초)
```

## 넣는 법

1. `configs/audio_assets.yaml` 의 `file:` 경로와 **파일명을 정확히** 맞춘다
   (파일명은 ASCII — 한글 파일명은 scp 로 젯슨에 보낼 때 깨진다).
2. 같은 파일의 `license:` 를 실제 근거로 갱신한다.
3. 빠진 파일 확인:

```bash
conda activate jaeha_bot && python -m app.audio_player
```

목록에 있는데 파일이 없으면 그 항목은 **자동으로 '못 하는 것'이 된다.**
`playable()`/`titles()` 가 걸러 주므로 봇이 없는 노래를 약속하지 않는다 —
그래서 파일을 아직 안 넣은 채로 목록만 적어 둬도 안전하다.

## 어디서 받나 — 공유마당 (2026-08-31 조사)

<https://gongu.copyright.or.kr> → **음악** → 검색. `configs/audio_assets.yaml` 의
`license:` 에 적어 둔 **UCI 코드(G905-…)** 로 바로 찾을 수 있다.

받을 수 있는 것이 두 갈래고 **성질이 다르다**:

| | 라이선스 | 가창 | 내용 |
|---|---|---|---|
| A | 기증저작물 자유이용 | **있음** | 차용운 창작동요 10곡(MBC 뽀뽀뽀). 23초~1분 11초 |
| B | CC BY | **없음** | 한국저작권위원회 국악연주곡. 작은별·비행기·전래동요 |

B 는 곡(만료)과 녹음(CC BY) **두 층이 다 풀린** 드문 음원이지만 **부르지는 않는다.**
아이에게 '노래를 틀어 준다'가 성립하는 건 A 쪽이다.

❌ **나비야·곰 세 마리·머리 어깨 무릎 발·산토끼는 공유마당에 없다**(검색 0건).
   이 넷은 직접 녹음이 가장 빠르다. 다시 찾아 헤매지 말 것.

## ⚠️ 저작권

시연·논문에 들어가는 물건이라 그냥 넘기면 안 된다. 안전한 순서:

1. **PD** — 저작권 만료·전래·외국 민요 (나비야, 반짝반짝 작은별, 머리 어깨 무릎 발)
2. **직접 녹음** — 부모 목소리가 가장 안전하고, 2세에게는 효과도 가장 좋다
3. **CC0 / CC-BY** — 출처와 라이선스를 `license:` 에 남길 것
4. **구매**

❌ 상업 창작동요(핑크퐁 '아기상어' 등)를 그대로 넣으면 안 된다.

## 젯슨 배포

`push_code.sh` 는 `app configs scenarios data` 만 보낸다 — **assets 는 안 간다**(용량).
음원을 바꿨을 때만 따로 보낸다:

```bash
scp -r assets jaeha_bot@100.65.22.17:~/jaeha_bot/
```

## 형식 권장

| | 형식 | 레이트 | 채널 |
|---|---|---|---|
| 동요 | mp3 | 원본 그대로 | 무관(재생 시 모노로 합침) |
| 효과음 | wav | 16000 | 모노 |

재생 시 장치가 못 받는 레이트는 자동 리샘플된다(젯슨 ReSpeaker 는 16000 전용).
스테레오는 모노로 합쳐 나간다 — 스피커가 하나라 한쪽 채널만 나가는 사고를 막기 위해.
