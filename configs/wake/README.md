# 호출어(KWS) 학습 설정

여기 있는 건 **학습 설정**이지 실행 설정이 아니다. 봇은 이 파일들을 읽지 않는다 —
런타임이 쓰는 건 ONNX 3종이고, 그 경로·임계값은
`configs/model_paths.yaml` 의 `wake:` 섹션에 있다.

`models/` 는 `.gitignore` 에 걸려 git 이 추적하지 않는다.
그 안에 학습 설정을 두면 **어떤 설정으로 만든 모델인지가 로컬 파일 하나에만 남는다.**
그래서 설정만 여기로 옮겼다(2026-08-05).

| 파일 | 용도 |
|---|---|
| `jaeha_v1.yaml` | `jaehabot.onnx` 를 만든 설정 (2026-08-02 학습). 현재 **롤백용**으로만 남김 |
| `jaeha_v2.yaml` | voxcpm 프롬프트 수정안 (**폐기 — 실행했으나 생성물이 불량이었다**) |
| `jaeha_v3.yaml` | **배포 중인 `jaehabot_v3.onnx` 를 만든 설정** (2026-08-09 학습) |

⚠️ `jaeha_v3.yaml` 의 `tts_backend: voxcpm` 을 곧이곧대로 읽지 말 것 — v3 음성은 전부
Supertonic 으로 만들었고 generate 는 배경음 폴더용으로만 돌렸다. 파일 머리말에 적어 뒀다.

젯슨 배치(2026-08-09): v3 는 `models/wake/v3/`, v1 은 `models/wake/` 에 그대로.
**롤백 = `model_paths.yaml` 의 `model_dir`·`classifier` 두 줄 되돌리기.**
멜·임베딩 onnx 는 v1 과 바이트 동일(md5 대조) — 바뀐 건 분류기뿐이다.

학습은 노트북이 아니라 Colab 에서 돌린다(`livekit-wakeword` 가 py≥3.11 요구,
젯슨은 3.10). 노트북: `tools/colab_wake_train_v3.ipynb`(v3, 저장소에 있음),
`Downloads/colab_wakeword_jaeha_ver2.ipynb`(v2, 폐기).
결정 근거·운영 함정은 메모리 `wake-tool-decision` 참조.

## v2 → v3 에서 바뀐 것 (2026-08-09)

- **TTS 를 voxcpm → Supertonic 으로 교체.** v2 를 돌려 보니 voxcpm 이 만든 긍정 샘플이
  '재하봇'을 말하지 않았다(25초 폭주 포함). A/B 4변형 최고 통과율 40% → 손댈 노브가 없었다.
  Supertonic 은 검수 통과율 **91%**, 폭주 0건, 생성 4.5시간 → **22분**.
- **빠른 발화를 프롬프트가 아니라 신호처리로 만든다.** 합성 속도는 안전구간(0.85~1.05)만 쓰고,
  검수 통과본을 리샘플로 압축(1.15/1.25/1.35배)한다. 피치도 같이 올라가 유아 음역까지 덮인다.
  ⚠️ 부정 샘플에도 **같은 배속**을 걸었다 — 긍정에만 걸면 '빨라진 소리 = 호출어'를 배운다.
- 학습 하이퍼파라미터(steps·model_size·augment·batch_*)는 **v1/v2 그대로.**

## v1 → v2 에서 바뀐 것 (폐기된 안)

- `voice_design_prompts` 6 → 16개 (**빠름 7 / 보통 6 / 느림 3**).
  v1 은 한국어로 옮기면서 속도 묘사를 전부 빠뜨려 긍정 샘플이 죄다 보통~느린 속도였다.
  그래서 실기에서 "천천히는 되는데 빠르게 부르면 안 됨"이 났다.
  ⚠️ `length_scales` 는 Piper 전용 키라 voxcpm 백엔드에선 무시된다 — 속도는 **프롬프트 텍스트로만** 바꾼다.
- `target_phrases` 5 → 7개: 재하봇 / 제하봇 / 재하봇아 / 재하보사 / 재하부사 / 재하봇이 / 재하보시.
  호격 '~아'가 연음으로 [재하보사] 로 실현되는데 voxcpm 이 연음을 살린다는 보장이 없어 발음형을 병기했다.
- `n_samples` 2000 → 3000 (프롬프트가 늘어 프롬프트당 187개 확보). **생성 4~4.5시간.**
- 나머지(부정문구·steps·model_size·augment)는 v1 그대로 — 변수를 하나만 바꿔야 효과 판정이 된다.

## 성적

| | v1 (2026-08-02) | v3 (2026-08-09) |
|---|---|---|
| AUT | 0.0302 | **0.0011** |
| Recall @ thr 0.50 | 40.1% | **91.1%** (FPPH 0.09) |
| 배포 임계값 | 0.15 → recall 58.2% / FPPH 2.18 | **0.30 → 94.3% / FPPH 0.33** |

🔴 **두 열을 직접 비교하면 안 된다 — 시험지가 다르다.** v1 의 평가셋은 voxcpm(재하봇이라
말하지 않던 그 음성)이고 v3 는 Supertonic 이다. 게다가 v3 평가셋은 학습셋과 **같은 화자·
같은 문구·같은 속도**로 만들어졌고 다른 건 시드뿐이라, 91% 는 "Supertonic 분포를 학습했다"는
뜻이지 실제 아이 목소리 재현율이 아니다. **최종 판정은 젯슨 실기**(천천히/보통/빠르게 각 10회).

배포 임계값을 곡선상 최적(0.50)이 아니라 0.30 으로 잡은 이유도 이것 — 실제 재현율이
합성보다 떨어질 여유를 둔 값이다. 그래도 오작동은 v1 배포점보다 6배 낮다.
참고: 부정 클립 최고 점수가 0.284 라 **0.20 으로 내리면 그 클립이 헛깨움이 된다.**
