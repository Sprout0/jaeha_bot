# F1+F4 를 기준으로 '다른 성분을 빼는' 후보들 (2026-08-19)
#
# 사용자가 F1 과 F4 를 마음에 들어 했다. 여기서 외삽(음수 가중치)으로 다른 화자
# 성분을 빼면 "더 F1·F4 다운" 목소리가 된다 — 어떤 프리셋보다도.
#
# 돌리는 법 (젯슨):
#   python tools/voice_knockout.py --specs-file data/voice_candidates.txt --k 2
#
# 🔴 현행 목소리는 도구가 **몰래** 끼워 넣는다. 블라인드에서 현행이 이기면
#    '바꿀 이유가 없다'가 결론이고, 그것도 결과다.
# ⚠️ 가중치 합은 전부 1.0 이다. 음수를 크게 주면(-0.4) 스타일 벡터가 학습 분포
#    밖으로 나가 소리가 깨질 수 있다. 깨지면 그 줄을 지우고 다시 돌리면 된다.

# ── 대조군 ────────────────────────────────────────────────────────────────────
F1+F4                          # 지금 마음에 든 균등 블렌드. 이게 이기면 끝이다
F3:-0.2+F1:1.2                 # 어제 블라인드 우승자 (F4 가 없는 쪽)

# ── 여성 프리셋을 뺀다 ────────────────────────────────────────────────────────
F1:0.6+F4:0.6+F2:-0.2
F1:0.6+F4:0.6+F3:-0.2          # 어제 우승 방향(-F3)을 F4 와 섞은 것
F1:0.7+F4:0.7+F3:-0.4          # 같은 방향으로 두 배 세게
F1:0.6+F4:0.6+F5:-0.2

# ── 남성 성분을 뺀다 ──────────────────────────────────────────────────────────
# 목표가 '더 어린이 같은 목소리'라, 성인 남성 성분을 빼는 게 이론상 가장 직접적이다.
F1:0.6+F4:0.6+M1:-0.2
F1:0.7+F4:0.7+M1:-0.4
F1:0.6+F4:0.6+M3:-0.2

# ── F1 / F4 기울기도 같이 본다 ────────────────────────────────────────────────
F1:0.85+F4:0.35+F3:-0.2        # F1 쪽으로 기울임
F1:0.35+F4:0.85+F3:-0.2        # F4 쪽으로 기울임

# ── 음색은 빼되 리듬은 순정으로 ───────────────────────────────────────────────
# 외삽하면 말투까지 같이 튄다. 음색만 가져오고 리듬은 F1 그대로 두는 조합.
F1:0.6+F4:0.6+M1:-0.2|F1
