# 목소리 후보 (2026-08-19 재작성 · 목표 = '티니핑 같은 친숙한 애니 목소리')
#
# 공식 프리셋 성격 (supertone-inc.github.io/supertonic-py/voices/):
#   F1  차분·**약간 낮은 톤**, 안정적       (고객응대·명상)
#   F2  밝고 명랑, **장난기, youthful**      (청소년·SNS)   <- 목표에 가장 가깝다
#   F3  또렷한 **아나운서** 톤, 방송용       (광고·격식 내레이션)
#   F4  선명·자신감, 표현력                  (비즈니스 설명)
#   F5  친절·부드러움, 차분                  (오디오북·웰니스)
#   M2  깊고 묵직, 침착                      <- '성인 저음'. 빼기 좋은 대상
#
# 🔴 목표가 바뀌면서 축이 F1 에서 F2 로 옮겨갔다.
#    티니핑류(유아 애니 요정 캐릭터)는 **높고 밝고 장난기 있는** 목소리다.
#    F2 가 유일하게 그쪽이고, F1 은 공식 설명부터가 '약간 낮은 톤'이라 정반대다.
#    ⚠️ 즉 **사용자가 좋다고 한 F1+F4 와 이번 추천은 서로 반대 방향이다.**
#       그래서 F1+F4 계열을 대조군으로 남겨 뒀다 — 블라인드가 판정하게 한다.
#
# 🔴🔴 핵심: **음색과 리듬을 갈라야 한다** (아래 ★ 표시)
#    2026-08-18 에 이미 겪었다 — 밝은 음색을 가져오면 촐랑거리는 리듬이 딸려오고,
#    2세에겐 그게 알아듣기 어렵다. 티니핑 목소리는 **빠르고 들뜬 말투**까지 같이 온다.
#    `음색|리듬` 문법으로 **밝은 음색 + 차분한 말투**를 만들 수 있다. 이게 이 목록에서
#    가장 기대되는 자리다: 친숙함은 얻고 알아듣기는 안 잃는다.
#
# 돌리는 법 (젯슨):
#   python tools/voice_knockout.py --specs-file data/voice_candidates.txt --k 2
#
# 🔴 현행 목소리는 도구가 몰래 끼워 넣는다(총 14명). 현행이 이기면 '바꿀 이유 없음'이 결론이다.
# ⚠️ 가중치 합은 전부 1.0. 음수가 크면 스타일 벡터가 학습 분포 밖으로 나가 소리가
#    깨질 수 있다. 깨지면 그 줄을 지우고 다시 돌리면 된다.

# ── 대조군 ────────────────────────────────────────────────────────────────────
F1+F4                          # 사용자가 좋다고 한 것 (이번 추천과는 반대 방향)
F3:-0.2+F1:1.2                 # 어제 블라인드 우승
F2                             # 순정 F2. **티니핑 방향의 기준점** — 이게 이기면 단순한 게 답이다

# ── F2 를 주역으로 (티니핑 방향) ──────────────────────────────────────────────
F2:0.7+F1:0.3                  # 밝게, 다만 차분함을 조금 남긴다
F2:0.7+F4:0.3                  # 밝게 + 또렷한 표현력
F1:-0.2+F2:1.2                 # 외삽 — F2 에서 **차분함을 뺀다**. 어떤 프리셋보다 발랄

# ── F2 + 빼기 (더 밀어붙이기) ─────────────────────────────────────────────────
F2:0.8+F4:0.4+M2:-0.2          # 성인 저음을 뺀다
F2:0.8+F4:0.4+F3:-0.2          # 방송 아나운서 느낌을 뺀다
F2:0.9+F4:0.4+F1:-0.3          # 낮은 톤을 뺀다 (티니핑은 높은 톤)

# ── ★ 음색은 티니핑, 리듬은 차분 (가장 기대되는 자리) ─────────────────────────
F2:0.7+F4:0.3|F1               # 밝은 음색 + F1 의 차분한 말투
F2:0.8+F4:0.4+M2:-0.2|F1       # 위에 저음 빼기까지
F2:0.7+F4:0.3|F5               # 밝은 음색 + F5 의 부드러운 말투

# ── 반대 방향 대조 ────────────────────────────────────────────────────────────
F1:0.6+F4:0.6+F3:-0.2          # 어제까지의 방향(차분 유지). 정말 F2 쪽이 나은지 확인용
