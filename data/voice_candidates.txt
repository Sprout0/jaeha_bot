# F1+F4 기준 후보 (2026-08-19, 공식 프리셋 설명 반영해 재작성)
#
# 🔴 공식 문서에 프리셋별 성격이 있다 (supertone-inc.github.io/supertonic-py/voices/):
#     F1  차분·약간 낮은 톤, 안정적          (고객응대·명상용)
#     F2  밝고 명랑, 장난기, **youthful**     (청소년·SNS용)   <- 목표에 가장 가깝다
#     F3  또렷한 **아나운서** 톤, 방송용      (광고·격식 내레이션)
#     F4  선명하고 자신감, 표현력             (비즈니스 설명·제품 안내)
#     F5  친절하고 부드러움, 차분             (오디오북·웰니스)
#     M2  깊고 묵직, 침착                     <- '성인 저음' 성분. 빼기 좋은 대상
#
# 이 라벨이 리스트를 두 군데 바꿨다:
#   ① F2 는 **더해야** 한다. 공식 설명상 유일하게 'youthful·playful' 이다.
#      (사용자가 1단계에서 고른 것도 F1·F2·F4 였다. F2 가 중간에 빠져 있었다.)
#   ② 남성 성분은 M1 이 아니라 **M2(깊고 묵직)** 를 빼는 게 정타다.
#   그리고 어제 블라인드 우승 `F3:-0.2+F1:1.2` 는 라벨을 모르고 고른 건데
#   결과적으로 '차분한 목소리에서 아나운서 느낌을 뺀 것'이었다. 방향이 맞았다는
#   독립적인 뒷받침이다.
#
# ⚠️ 라벨은 어디까지나 사전 정보지 증거가 아니다. 판정은 블라인드가 한다.
#    그래서 '라벨상 반대 방향'인 F2 빼기도 대조로 한 줄 남겨 뒀다.
#
# 돌리는 법 (젯슨):
#   python tools/voice_knockout.py --specs-file data/voice_candidates.txt --k 2
#
# 🔴 현행 목소리는 도구가 몰래 끼워 넣는다(총 14명). 현행이 이기면 '바꿀 이유 없음'이 결론이다.
# ⚠️ 가중치 합은 전부 1.0. 음수를 크게 주면(-0.4) 스타일 벡터가 학습 분포 밖으로
#    나가 소리가 깨질 수 있다. 깨지면 그 줄을 지우고 다시 돌리면 된다.

# ── 대조군 ────────────────────────────────────────────────────────────────────
F1+F4                                   # 지금 마음에 든 것. 이게 이기면 끝이다
F3:-0.2+F1:1.2                          # 어제 블라인드 우승
F1+F2+F4                                # 1단계에서 직접 고른 셋 전부

# ── F3(아나운서) 빼기 · 근거가 가장 강하다 ────────────────────────────────────
F1:0.6+F4:0.6+F3:-0.2
F1:0.7+F4:0.7+F3:-0.4                   # 같은 방향으로 두 배 세게
F1:0.45+F2:0.45+F4:0.3+F3:-0.2          # 발랄함을 넣고 방송톤을 뺀다

# ── F2(발랄·유아틱) 더하기 ────────────────────────────────────────────────────
F1:0.4+F2:0.35+F4:0.25
F1:0.3+F2:0.5+F4:0.2                    # F2 를 주역으로

# ── M2(성인 저음) 빼기 ────────────────────────────────────────────────────────
F1:0.6+F4:0.6+M2:-0.2
F1:0.5+F2:0.4+F4:0.3+M2:-0.2

# ── 두 방향 동시에 ────────────────────────────────────────────────────────────
F1:0.5+F2:0.4+F4:0.4+F3:-0.15+M2:-0.15  # 방송톤도 빼고 저음도 빼고 발랄함은 넣고

# ── 음색과 리듬을 갈라서 ──────────────────────────────────────────────────────
F1:0.6+F4:0.6+F3:-0.2|F2                # 음색은 차분, 말투만 발랄하게

# ── 반대 방향 대조 (라벨이 틀렸을 수도 있으니) ────────────────────────────────
F1:0.6+F4:0.6+F2:-0.2                   # 발랄함을 오히려 빼면?
