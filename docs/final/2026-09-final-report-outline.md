## 1장. 문제 정의 — 왜 2세 유아 음성 AI 가 어려운가

**논지:** 성인용 부품을 그대로 쓰면 아이에게서 무너진다. 우리는 그걸 *추정이 아니라
재현 실험으로* 보였다.

| 근거 | 수치 | 출처 |
|---|---|---|
| 유아 STT 한계(문헌) | Whisper 5세 WER 21% | 메모리 `research-child-stt-robots` |
| 아동 발화 인식(우리 실측) | AI-Hub 3\~6세 로컬 medium **CER 31.5%** (153발화·화자 114명). 연령별 3세 44.3% / 4세 32.1% / 5세 28.1% / 6세 23.6% | `reports/stt/README.md`, `reports/stt/young/detail_medium.json` |
| 종료점 검출 실패 | Smart Turn v3.2 재현율 **벤더 성인 한국어 97.8% vs 우리 AI-Hub 3~6세 37.3%** (같은 코드 경로) | `reports/turn/README.md` (요약·재계산 확인), `tools/eval_turn_detect.py` |
| 아이 발화 특성 | 내부 쉼 p90 **0.32초** | 위와 같은 채점 |

🔴 **CER 은 숫자가 두 벌이다 — 섞지 말 것.** 31.5% 는 3\~6세 **153발화 전체**(2026-08-18)이고,
   7장의 40.2% 는 S2S 와 나란히 비교하려고 **같은 39발화만 같은 자로 다시 채점한 부분집합**
   (2026-09-02, `reports/bench/README.md`)이다. **1장은 31.5%, 7장은 40.2%** 로 쓰고, 7장에서는
   '같은 발화·같은 채점'이라고 반드시 밝힌다. 한 문서에 근거 없이 두 값이 나오면 그것부터 질문받는다.

➡️ 1장의 결론이 곧 **특허 후보 ①(아동 종료점 적응 검출)의 '과제'** 다. 같은 문단을
   두 문서가 나눠 쓴다.

## 3장. 설계 결정과 근거 🟢 **이 프로젝트의 핵심 자산**

각 항목을 `결정 ↔ 대안 ↔ 실측 근거` 형식으로. 아래는 후보 목록:

- **호출어를 '재하봇' → '하이 티드' 로 교체** — whisper 가 힌트 없이 36개 중 35개 정확 전사
  (중앙 0.000/최대 0.222) vs '재하봇' 0.429·정타 0회. 검증 1.7s → 0.85s.
- **2단계 검증에 임베딩 대조 추가** — whisper 가 호출어를 '안녕히계세요'로 환각한다
  (증거 wav 있음). 임베딩 14/15 vs whisper 10/15.
- **STT medium 고정 + VAD 1.2s**
- **TTS TensorRT @24 스텝** — 합성 829.5 → 371.9ms(−457ms). TRT@12 는 튀는 소리로 기각.
- **필러(맞장구) 삽입** — 설계 목표: 체감 침묵 4.17 → 1.70s, 실지연 0.
  ⚠️ **1.70s 는 설계 계산치다.** 08-26 에 '0.6~0.7초 늦춰 답에 붙여 낸다'로 바뀐 뒤 실기 첫소리 시각을
  잰 적이 없다. 효과로 쓰려면 먼저 재야 한다. 확실한 값어치는 **아이 재발화 차단**(filler.py 참조).
- **소리 트리거는 LLM function calling 이 아니라 낱말 규칙** — 모델은 의역을 잡지만
  랜덤 헛호출을 한다. 아이 대상에서 헛호출 = 원치 않는 소리가 갑자기 나감.
- **음악은 스트리밍이 아니라 파일 재생** — 서비스 약관 조사 결과 전 경로 폐쇄.

## 4장. 실측으로 기각한 것들 🟢 **가장 강한 장. 여기를 두껍게 쓴다**

음수 결과를 방법과 함께 가진 학부 프로젝트는 드물다. 각 항목 `가설 → 측정 방법 →
결과 → 왜 기각`:

- Smart Turn v3.2 (아이에게서 무너짐 / 도구는 벤더 데이터 99.4%로 자체 검증)
- 클로바(HCX) 전환 — LLM 에서 번 0.39s 를 말하기에서 도로 씀. 재실행 시 순위가
  뒤집혀 **실행 간 변동 ~1.0초**, 즉 '구분 불가'가 정확한 결론.
- 2패스 호출어 검증 — 전수 로그에서 뒤집은 사례 0건
- TTS 버킷팅 / 문장 스트리밍(이득 0.047초) — 합성은 고정비용이 지배적
- 선행 생각 — 실기 발동 0회(인식이 꼬리보다 늦게 끝난다)
- 1단계 단독 호출어 — 실제 거실 160회/시간 (오프라인 추정의 23배)
- Nemotron·zipformer-ko 한국어 파인튜닝 STT — 환각

**+ 방법론 교훈 (별도 절):** 측정 도구가 틀려서 결론이 뒤집힌 3건. 이걸 쓰는 것이
정직할 뿐 아니라 강하다.

- ✅ **젯슨에서 검증됨 (2026-09-07)**: 오디오 출력 경로, 리샘플, 음원 재생.

- ✅ **호출어→대화→응답 한 바퀴 (2026-09-07, 5턴)** — 전 구간이 젯슨에서 살아 있음을
  처음으로 통째로 확인. 원본 계측 `reports/jetson/metrics_20260907.jsonl`.
  마이크 소음바닥 0.00698(죽으면 0.00000), 호출어 자모거리 0.00 **1패스** 통과.

- ❌ **음향 결합 계층 미검증** — 스피커 미보유. `PLAY_PAD_S=0.15` 는 도입 이래 한 번도

  `tools/measure_play_pad.py` 에 준비되어 있어 스피커 확보 시 즉시 실행 가능하다.

## 7장. 다음 단계 — 전면 API(S2S)로의 전환 ✅ **채택됨**

> 2026-09-09 에 **개발 방향으로 채택됐다.** 이 장은 "해볼 만한 아이디어"가 아니라
> **"측정으로 근거를 세운 뒤 실제로 채택한 결정"** 이다. 그 편이 훨씬 강하다.
> 구현 자체는 이 문서의 범위 밖이다(문서 대상은 현행 파이프라인).

- 꼬리 1200ms 동일 조건에서 **1.95s vs 현행 3.5s = −1.55초** (프로젝트 최대 이득)
- 아이 발화 인식이 로컬보다 낫다: CER **36.9%**(Realtime + `gpt-4o-transcribe`) vs
  **40.2%**(로컬 medium) — **같은 39발화·같은 자로 채점한 부분집합**이라 1장의 31.5%(153발화)와
  다른 값이다. 단 `whisper-1` 은 39% 빈 문자열로 결론이 뒤집힌다 —
  전사 모델 선택이 필수 조건.
- 출력 전사가 오디오보다 먼저 도착 — 원자료가 있는 OpenAI 51턴 중 50턴 0.146~0.244초, **1턴은 0**.
  (09-02 의 0.19초는 README 요약만 있고 원자료 파일이 저장소에 없다.) Gemini 3.1 은 늘 0.000초.
  → 재생 전 안전 검사는 **OpenAI 에서, 대부분의 턴에서만** 가능하다
- 비용 턴당 $0.0017, 이력 누적이 제곱으로 증가 → 이력 절단 필요
- 미해결: 젯슨 적용, 목소리 F2 대체, 폴백, 원음 해외 전송
- **전환의 선결 조건 — 호출어**: 로컬 STT 가 사라지면 호출어 2단계 검증이 whisper
  전사에 기댈 수 없다. `verify.mode: embed`(임베딩 단독)로 바꿔야 하고, 그 임계값은
  거실 소음 30\~60분 녹음으로 정해야 한다(`docs/superpowers/plans/2026-09-02-*` Task 0).
  코드는 준비돼 있고 기본은 꺼져 있다.
- ⚠️ **호출어는 API 로 못 보낸다.** 항상 듣고 있어야 하므로 비용·지연·프라이버시가
  전부 무너진다. "전부 API" 의 명시적 예외다.
- ⚠️ **끊기면 멈춘다.** 현행은 로컬 GGUF 폴백이 받치지만 전면 API 에는 그게 없다.
- 🔴 **정책·법이 속도보다 먼저 막는다 (2026-09-11 조사)** — Gemini API 약관은 18세 미만이 접근할 가능성이 있는
  앱을 금지한다(아동용 탈락). OpenAI 는 13세 미만 개인정보에 **ZDR 을 먼저** 요구하는데, `/v1/realtime` 은
  ZDR 대상이지만 **사전 승인제**라 학교 명의 신청이 선결이다(기본은 남용 감시 30일 보관, 한국 리전은 저장만 되고
  처리는 해외). 대학 연구는 개인정보보호법이 적용된다(법정대리인 동의, 국외 이전 근거).
- **Moxie(2024)** — 클라우드에만 의존한 아동 로봇이 회사 폐업으로 통째로 먹통이 됐다. → 로컬 경로(현행
  파이프라인)는 박제가 아니라 **아동 음성 보호 경로이자 폴백**으로 남긴다.
