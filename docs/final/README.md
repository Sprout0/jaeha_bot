## 서술 대상

보고서가 서술하는 것은 전면 API 전환 이전의 로컬 파이프라인이며, 그 상태를 태그로
고정해 두었다.

```
git checkout doc-baseline-2026-09-12
```

개발은 2026년 9월 9일 회의에서 전면 API로 방향이 전환되었다. 전환 이후의 코드가 이
문서의 서술 대상을 지우지 않도록, 본문이 인용하는 코드와 측정 도구는 `main`에 남긴다.

(이전 태그 `doc-baseline-2026-09`는 9월 11일 작업 — 노래 재생 기능과 호출어 검증
수정 — 을 포함하지 않는다. 본문이 그 두 항목을 서술하므로 태그를 다시 잡았다.)

## 아직 정해지지 않은 것

- **문서 형식.** 결과보고서 양식 / 논문 형식 / 자유 중 미정이다. `report.md`는 형식
  중립으로 작성하였으므로, 결정되면 해당 양식에 옮긴다. 표와 그림은 그대로 쓸 수 있다.
- **합격선.** 실기 시연 / 영상과 보고서 / 문서만 중 미정이다. 어느 쪽이어도 데모 녹화가
  필요하다.
- **특허 출원 여부.** 출원하는 경우 보고서 공개 전에 임시명세서를 내는 것이 가장 단순
  하다(특허 문서 6절).
- **아동 음성의 처리 경로.** 기관 명의의 ZDR 신청과 로컬 처리 유지 중 선택이 필요하다
  (본문 7.4절).

## 수치를 고칠 때의 규칙

본문의 모든 수치는 `reports/` 원본과 대조한 값이다. 새 수치를 넣거나 고칠 때는 원본
파일을 근거로 삼고, 부록 B의 대응표에 출처를 추가한다. 이 프로젝트는 측정 도구의 결함으로
결론이 뒤집힌 사례가 네 건 있었고(본문 4.8절), 모두 원본으로 돌아가 확인하는 과정에서
발견하였다.
