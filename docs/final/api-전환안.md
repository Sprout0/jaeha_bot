## 1. 측정 결과

### 1.1 응답 지연

성인 실음성 8클립을 동일한 무음 대기 조건에서 측정하였다.

| 구성 | 종료 판정 | 첫 소리까지 | 합계 |
|---|---|---|---|
| 현행 로컬 | 1.20초 | 약 2.30초 | **약 3.50초** |
| OpenAI Realtime (무음 1200ms) | 1.44초 | 0.50초 | **1.95초** |
| 구글 Gemini 3.1 Flash Live | — | — | **1.70초** |

동일 조건에서 1.55초 단축된다. 본 과제에서 측정된 어떤 개선보다 크다.

### 1.2 아동 발화 인식

AI-Hub 3~6세 발화를 동일 채점 기준으로 비교하였다.

**(가) 발화마다 새 세션** — 동일 발화를 같은 채점 기준으로 비교하였다.

| 구성 | 문자 오류율 | 완전 일치 | 빈 전사 |
|---|---|---|---|
| OpenAI Realtime + `gpt-4o-transcribe` | **36.9%** | 10/39 | 0% |
| 구글 Gemini 3.1 Flash Live | 40.8% | 12/40 | 0% |
| 로컬 medium (동일 발화 재채점) | 41.7% | 10/40 | — |
| OpenAI Realtime + `whisper-1` | 62.9% | 4/39 | **39%** |

**(나) 대화를 이어간 경우(40턴)** — 같은 조건에서 두 공급자의 방향이 갈린다.

| 구성 | 단발 | 40턴 누적 |
|---|---|---|
| OpenAI | 36.9% | **33.7%** (개선) |
| 구글 Gemini | 40.8% | 48.8% (악화) |

세 가지를 함께 기록한다.

1. **전사 모델 선택이 결론을 뒤집는다.** `whisper-1`은 39% 확률로 빈 문자열을 반환하며,
   그 경우 안전 검사와 로그가 처리할 재료가 사라진다. `gpt-4o-transcribe`를 지정해야 한다.
2. **구글은 긴 발화의 뒷부분을 버린다.** 완전 일치는 셋 중 가장 많지만 평균은 나쁘다.
   짧고 또렷한 발화는 맞히고 긴 발화를 잘라낸다. 입력 전사가 대화 모델의 부산물이라
   받아쓰기보다 요약에 가깝게 동작하는 것으로 보인다. 아동 발화를 기록으로 남겨야 하는
   용도(안전 필터, 연구 로그)에는 불리한 성질이다.
3. **OpenAI 채택 근거 하나가 구글에는 없다.** 전환을 재검토한 이유 중 하나가 "로컬보다
   잘 알아듣는다"였는데, 구글은 로컬과 사실상 동률이다.

### 1.3 비용

입력이 턴마다 누적되지만, OpenAI는 이전 대화분을 캐시 단가(음성 입력 정가의 3%)로 처리한다.
40턴째 입력의 92%가 캐시였고 턴당 비용은 2.9배만 증가하였다. 구글은 캐시가 적용되지 않아
같은 조건에서 22배가 되었다. (현행 구성은 월 4,100원)

| 세션 길이 (하루 3세션) | OpenAI mini | 구글 3.1 Live |
|---|---|---|
| 10턴 | 월 3,700원 | 월 5,200원 (무료 등급 내) |
| 20턴 | 월 9,100원 | 월 18,800원 |
| 40턴 | 월 21,200원 | 월 73,500원 |

아동 발화 40개를 한 세션으로 이어 실측, 1달러 1,400원. 이전 판의 OpenAI 값(10턴 5,400원,
40턴 71,000원)은 캐시를 반영하지 않은 추정치였다.

---|---|---|
| 10턴 | 월 5,400원 | 무료 등급 내 |
| 40턴 | 월 71,000원 | 월 73,000원 |

## 2. 제약 사항

### 2.1 약관 및 법령 — 성능보다 먼저 검토되어야 함

| 대상 | 내용 |
|---|---|
| 구글 Gemini API | 추가 서비스 약관이 **18세 미만이 접근할 가능성이 있는 애플리케이션**에 서비스 사용을 금지한다. 본 과제는 대상 연령이 만 2세이므로 적용 대상이 아니다 |
| OpenAI | 만 13세 미만의 개인정보 처리에 **데이터 무보관(ZDR) 적용을 선행 요구**한다. `/v1/realtime`은 ZDR 적용 대상이나 사전 승인제이며 종량제 계정에는 적용되지 않는다. 기본 상태에서는 남용 감시 목적으로 30일간 보관된다 |
| 국내 법령 | 대학 연구 과제는 개인정보 보호법의 적용을 받는다. 만 14세 미만은 법정대리인 동의, 국외 이전은 별도 근거가 필요하다 |

한국 리전을 선택하더라도 저장 위치만 국내이며 처리는 국외에서 이루어진다.

### 2.2 기술적 선결 조건

| 항목 | 내용 |
|---|---|
| 호출어 | API로 전송할 수 없다. 상시 대기가 필요하므로 비용·지연·사생활이 모두 성립하지 않는다. 전면 API의 명시적 예외다 |
| 호출어 2단계 검증 | 로컬 인식이 제거되면 전사 판정을 쓸 수 없다. 임베딩 단독으로 전환해야 하며, 임계값은 거실 소음 30~60분 녹음으로 결정해야 한다 |
| 폴백 | 현행은 로컬 모델이 받치나 전면 API에는 대체 수단이 없다 |
| 재생 전 안전 검사 | 출력 전사가 오디오보다 먼저 도착하는 시간차를 이용한다. OpenAI는 51턴 중 50턴에서 0.146~0.244초의 여유가 있었고 1턴은 0이었다. **구글은 8클립 전부 0.000초로 이 수단이 존재하지 않는다** |
| 미측정 | Jetson 적용, 블라인드 평가로 선정한 목소리의 대체, 아동 원음의 국외 전송 |

## 3. 선택지

| 방안 | 응답 | 대가 |
|---|---|---|
| 1. 기관 명의 ZDR 신청 후 전면 API | 1.95초 | 승인 소요 기간이 불확실하다 |
| 2. 음성은 로컬, 텍스트만 API | 미측정 | 속도 이득 대부분을 포기한다. **현행 구성과 거의 동일하다** |
| 3. 현행 유지 | 4.14초 | 메모리 85%, 목표 미달 |

2안은 새로운 구성이 아니라 현행 구성 그 자체임을 밝혀 둔다. 현행 파이프라인은 이미
인식과 합성을 로컬에서 처리하고 응답 생성만 API로 호출한다.

---

## 4. 로컬 구성을 유지하는 이유

위 제약에 따라 현행 로컬 파이프라인의 성격이 달라진다. 문서화를 위해 고정한 과거의
구성이 아니라, **아동 음성을 외부로 전송하지 않는 유일한 경로이자 연결 실패 시의
대비 수단**이다.

참고 사례로, 클라우드에 전적으로 의존한 아동용 대화 로봇 Moxie는 2025년 1월 제조사
폐업과 함께 서버가 종료되어 판매된 기기 전체가 동작을 멈추었다.
