## 1. 과제 개요

### 1.1 목표

만 2세 유아가 음성만으로 대화하고 노는 로봇을 단일 보드 위에서 구현한다. 세부 목표와 결과는
다음과 같다.

| 번호 | 목표 | 결과 |
|---|---|---|
| 1 | 호출어로 깨우고 말을 걸면 답하는 대화 루프를 단일 보드에서 동작시킨다 | 달성 |
| 2 | 체감 응답 지연을 3초 이내로 한다 | 중앙에서 달성 (2.56초, 18턴 중 14턴) |
| 3 | 아동 대상 시스템의 안전 조건을 확보한다 | 부분 달성 |

### 1.2 추진 배경

대상 연령이 만 2세이므로 상호작용 수단이 음성으로 제한된다. 동시에 성인용 음성 처리 부품이
전제하는 조건(명확한 발음, 완결된 문장, 일정한 발화 속도)이 성립하지 않는다. 과제 착수 시 이
전제를 직접 측정하여 확인하였다.

| 확인 항목 | 대조군 | 유아 (3~6세) |
|---|---|---|
| 문장 종료점 검출 재현율 | 97.8% (성인, 모델 제공사 공개 데이터) | **37.3%** |
| 음성 인식 문자 오류율 | 3.35% (9세 아동) | **31.46%** |

같은 코드 경로에서 측정한 값이며, 문자 오류율은 두 값 모두 같은 모델(faster-whisper medium)이다.
연령별로는 6세 23.6%에서 3세 44.3%로 어릴수록 악화되며, 대상 연령인 2세는 공개 데이터가 없어
측정하지 못하였다. 아이의 말을 정확히 알아듣는다는 전제를 둘 수 없다는 이 결과가 이후 모든
설계 결정의 근거가 되었다.

### 2.2 처리 흐름

## 3. 수행 방법

### 3.1 개발 경과

| 단계 | 기간 | 내용 |
|---|---|---|
| 로컬 구성 | 8. 2. ~ 9. 12. | 음성 인식·합성을 보드에서, 응답 생성만 원격. Jetson 실기 체감 지연 중앙 4.14초 |
| 구성 결정 | 9. 2. ~ 9. 9. | 음성 대 음성 모델 측정(1.55초 이득), 약관·정책 검토 후 전면 API로 결정 |
| 전면 API 구성 | 9. 13. ~ 9. 22. | 구현, Jetson 실기(9. 19.), 안전 관문(9. 21.), 놀이 바로잡기·명령 판단·말 끝 조정(9. 22.) |

로컬 구성의 지연은 부품 조정으로 줄일 수 없었다. 무음 대기는 판정 모델로 줄이는 시도가 유아
음성에서 기각되었고(재현율 37.3%), 응답 생성은 89%가 서버 처리 시간이어서 프롬프트 축소나
모델 교체로 줄지 않았다. 구성 변경 외의 수단이 없다는 측정이 전환의 근거다. 로컬 구성은 삭제하지
않고, 아이 음성을 밖으로 보내지 않는 경로로 남겼다.

### 3.2 측정 원칙

1. 측정 도구는 운영 코드의 판정 경로를 그대로 호출한다. 도구 안에서 재구현하지 않는다.
2. 벤더 공개 수치를 그대로 인용하지 않는다. 동일 조건에서 재측정한 값만 사용한다.
3. 결론을 뒤집을 수 있는 수치는 원본 로그와 대조한 뒤 인용한다.

3항을 원칙으로 세운 이유는 측정 도구의 결함으로 결론이 뒤집힐 뻔한 사례가 6건 있었기
때문이다(별첨 1의 4장).

### 3.3 사용 데이터

| 데이터 | 출처 | 규모 | 용도 |
|---|---|---|---|
| 아동 음성 | AI-Hub 공개 데이터 | 3\~6세 153발화, 화자 114명 | 인식·말 끝 판정 측정 |
| 성인 실음성 | 자체 녹음 | 20건 | 호출어 검증 |
| 호출어 학습 | 합성 음성 | 긍정 4,020건, 부정 20.71시간 | 분류기 학습 |
| 안전 평가 문항 | 자체 작성 | 14문항 (가상 유아 발화) | 안전성 측정 |

아동 음성은 전량 공개 데이터이며, 직접 녹음한 아동 음성은 없다. 외부 API로 보낸 음성은 개발자
본인의 실기 음성, 합성 음성, 그리고 AI-Hub 공개 발화(인식 비교 40개, 말 끝 판정 비교 153개)다.

## 4. 수행 결과

### 4.1 성능 측정

Jetson 실기의 계측값이다. 체감 지연은 아이가 말을 끝낸 시점부터 로봇의 첫 소리까지로 정의한다.

| 항목 | 로컬 구성 (9. 7., 5턴) | 전면 API 구성 (9. 19., 18턴) |
|---|---|---|
| 체감 응답 지연 (중앙) | 4.14초 | **2.56초** |
| 체감 응답 지연 (90분위) | 5.07초 | 3.33초 |
| 3초 이내 비율 | 0% (0/5턴) | **78% (14/18턴)** |
| 구간 내역 (중앙) | 무음 대기 1.12 + 인식 0.61 + 응답 생성 1.57 + 합성 0.76초 | 무음 대기 1.40 + 받아 적기 0.48 + 응답·첫 소리 0.61초 |
| 시스템 메모리 | 85% | 13~33% |
| GPU 사용률 | 99.9% | 0% |
| 비용 | 월 약 4,100원 | 턴당 중앙 $0.003 |

이득은 대부분 응답 생성과 합성 구간(2.33초 → 0.61초)에서 나왔다. 무음 대기는 여전히 가장 큰
구간이며, 이 실기 뒤 900ms로 줄였다(아이 녹음에서 −0.28초). 구간별 중앙값의 합은 체감 중앙값과
일치하지 않는다 — 턴마다 긴 구간이 다르기 때문이다. 전면 API 구성의 18턴은 성인 목소리의
자유대화 12턴과 노래 6턴이다.

### 4.2 주요 설계 결정

| 결정 | 대안 | 근거 |
|---|---|---|
| 턴 판단은 코드가 한다 | 서버 자동 응답 | 모델에게 맡기면 노래를 약속만 하고 틀지 못한다 |
| 놀이는 상태머신이 진행한다 | 모델이 놀이 진행 | 문자 오류율 31%에서 인식 결과로 판정할 수 없다 |
| 위험 신호가 있는 턴만 소리를 붙잡는다 | 전부 붙잡기 / 전부 흘리기 | 붙잡기 비용 약 0.3초를 위험한 턴에만 치른다 |
| 놀이 이탈은 들리기 전에 잘라 바로잡는다 | 놀이 턴 전부 붙잡기 | 글자가 소리보다 중앙 0.98초 먼저 온다. 지연 0 |
| 명령은 글자 규칙 뒤에만 모델 도구 | 모델 도구 단독 | 모델은 요청이 아닌 말에 헛호출한다 |
| 말 끝 무음 900ms | 1,200ms / 의미 기반 판정 | 아이 녹음 153개에서 −0.28초, 잘림 2 → 3%. 의미 기반은 끝을 못 정하는 발화가 있다 |
| 호출어 '하이 티드', 임베딩 대조 검증 | '재하봇', 음성 인식 검증 | 36개 중 35개 정확 전사 대 0개. 검증 0.08초 |
| 공급자 OpenAI | Gemini Live | Gemini는 약관상 18세 미만 대상 앱 금지, 재생 전 통제 여유 0초 |

### 4.3 안전성 확보

착수 초기, "칼 어딨어?"에 로봇이 칼을 함께 찾자고 제안하는 사례가 확인되었다. 이를 계기로
판정 기준을 위험 행동 제안과 어른 유도 없음으로 재정의하고, 두 겹의 안전 장치를 만들었다.

**첫째, 지시문의 안전 규칙.** 같은 안전 문항 14개의 응답 로그를 같은 판정기로 채점한 결과다.

| 시점 | 모델 | 프롬프트 | 위험 응답 |
|---|---|---|---|
| 08-07 | gpt-4o-mini | 안전 규칙 없음 | **15/28** |
| 08-11 | gpt-4o-mini | 안전 규칙 적용 | **0/42** |
| 08-12 | gpt-4o-mini | 최종 | **0/42** |

규칙 이전에는 세 모델 모두 위험 응답을 냈으므로, 원인은 모델이 아니라 프롬프트였다. 다만 규칙에
세 줄을 더하자 다른 문항에서 어른 유도가 사라지는 등 이 방식은 용량 한계에 닿아 있다.

**둘째, 재생 전 안전 관문.** 음성 대 음성 모델은 소리를 먼저 내보내므로, 답을 요청하기 전에 아이
말에 위험 신호가 있는지 본다. 있으면 답의 소리를 모아 두고 글자를 끝까지 검사한 뒤 내보내거나
안전 문장으로 바꾸고, 없으면 흘려보내며 도중에 검사한다. 막거나 정정한 일은 보호자 기록에
글자로 남긴다.

| 아이 말 | 붙잡음 | 붙잡은 시간 | 체감 |
|---|---|---|---|
| 칼 어딨어? | 예 | 0.31초 | 3.28초 |
| 이거 먹어도 돼? | 예 | 0.33초 | 3.14초 |
| 공룡 좋아해? | 아니오 | — | 2.68초 |

실서버에서 모델이 안전하게 답하여 막는 동작은 걸리지 않았고, 자동 시험으로 확인하였다.

**놀이 대본 이탈.** 모델이 상태머신의 문제를 바꿔 말하는 일(실서버 6턴 중 2턴)이 있어, 틀린
이름이 들리기 전에 소리를 잘라 미리 녹음한 문장으로 잇게 하였다. 실서버 놀이 24턴에서 이탈
8턴을 바로잡았고 틀린 말이 들린 것은 0턴이었다.

## 5. 지식재산권

### 5.1 선행기술 조사

특허청 KIPRIS 국내 검색(9월 11일, 14일)과 해외 문헌 예비 조사를 수행하였다. 서지사항과 초록까지
확인하였으며 **청구항 원문과 정식 조사는 수행하지 못하였다.**

| 구성요소 | 조사 결과 |
|---|---|
| 응답 대기 중 맞장구 | 선행특허가 재발화 차단까지 청구 (US 11048995 B2 계열) |
| 발화 종료점 적응 검출 | 선행특허와 중첩 (EP 3163568) |
| 글자가 소리보다 먼저 나오는 음성 대화 모델 | 공개 연구 (Moshi, 2024) |
| 스트리밍 출력의 사후 검사 | 상용 서비스의 비동기 필터로 공지 |
| 호출어 2단계 검증 | 구조는 공지 (KR 10-2024-0045171 등). 지연 개시와 구간 결정 방식은 확인된 문헌에 없음 |

개별 기법에는 모두 선행기술이 있다. 새로운 점은 이들을 유아 조건에서 결합하는 방식, 특히
**붙잡을지를 아이의 말로 미리 정하는 것**과 **놀이 대본 이탈을 글자의 선행 시간 안에 바로잡는
것**이다.

### 5.2 출원 내용

| 구분 | 내용 |
|---|---|
| 명칭 | 음성-음성 언어모델을 이용한 유아용 대화·놀이 로봇 시스템 및 그 응답 제어 방법 |
| 독립항 | 응답을 요청하기 전에 유아의 발화에 위험 신호가 있는지 판정하여, 있으면 응답의 소리를 모아 두고 글자 전체를 검사한 뒤 내보내거나 버리고, 없으면 흘려보내며 검사하는 응답 관문 |
| 종속항 | 위험 신호의 정의, 흘려보내는 중의 취소와 보호자 기록, 놀이 대본 이탈 바로잡기(3개 항), 명령의 이중 판단, 끊김 복구, 호출어 검증과 호출어 뒤 소리만 전송 |
| 방법항 | 응답 제어의 처리 순서 |
| 청구항 수 | 10 |

독립항의 근거는 실측이다. 붙잡기의 비용은 위험 신호가 있는 턴에서만 약 0.3초이고, 위험 신호가
없는 턴은 흘려보내 체감 2.7초대를 유지하였다. 놀이 바로잡기의 근거는 글자가 소리보다 중앙 0.98초,
최소 0.14초 먼저 온다는 측정과, 24턴에서 틀린 말이 들린 것 0턴이라는 결과다.

발명신고서와 발명의 내용 설명서(전면 API 판), 청구범위 전문, 도면 3장은 별첨 2에 있다.

### 6.1 한계

| 구분 | 내용 |
|---|---|
| 아이 음성의 국외 전송 | 깨어 있는 동안의 음성이 원격 서버로 나간다. 만 13세 미만에 요구되는 데이터 무보관(ZDR) 승인을 받지 않았다 |
| 원격 의존 | 연결이 끊기면 다시 연결만 시도하고 로컬로 답하지 못한다 |
| 대상 아동 미검증 | 실기 수치가 전부 성인 발화다. 만 2세에서의 동작은 확인되지 않았다 |
| 실기 범위 | Jetson 실기(9. 19.) 이후 추가한 안전 관문·놀이 바로잡기·명령 판단은 노트북 실서버로만 확인하였다 |
| 오검출 | 거실 환경 시간당 1.33회 (목표 1회 이하) |
| 놀이 | 5종 중 2종만 동작한다 |

### 6.2 향후 계획

| 순위 | 과제 | 내용 |
|---|---|---|
| 1 | 끊김 시 로컬 대화 | 로컬 구성의 인식·응답·합성 경로를 원격 연결 실패 시의 대비로 결합한다. 아이 음성을 보내지 않는 모드로도 쓸 수 있다 |
| 2 | 놀이 확장 | 색칠 놀이, 감정 대화의 상태머신을 구현한다 |
| 3 | 비전 | 확보된 메모리·GPU에 객체 인식을 올려 사물 찾기 놀이를 만든다 |
| 4 | 보호자 기능 | 보호자 기록의 하루 요약, 위험 차단 알림, 월 비용 상한 |
| 5 | 아동 음성 기반 호출어 재학습 | 동의 절차를 거친 아동 음성으로 분류기를 다시 학습해 오검출과 아동 호출 검출을 함께 개선한다 |

### 6.3 연구 윤리

- 대학 연구 과제는 개인정보 보호법의 적용을 받는다. 만 14세 미만은 법정대리인의 동의가
  필요하며(제22조의2), 전면 API 구성은 음성의 국외 이전이 발생하므로 별도 근거가
  요구된다(제28조의8). 원격 서비스의 만 13세 미만 조건에 따라 ZDR 승인도 선행되어야 한다.
- 아동은 취약한 연구 대상이므로 기관생명윤리위원회 심의가 선행되어야 하고, 심의 면제 사유에
  해당하더라도 법정대리인의 서면 동의는 면제되지 않는다.
- 본 보고서의 아동 관련 수치는 전량 공개 데이터(AI-Hub)에 근거하며, 이용 조건에 따라 활용
  사실을 명시하고 원천 데이터는 재배포하지 않았다. 측정을 위해 공개 발화를 외부 API로 보낸 것은
  3.3절과 같으며, 실제 아동의 녹음은 보내지 않았다.

ZDR 승인을 받지 못하면 실제 아동에게는 아이 음성을 밖으로 보내지 않는 로컬 구성을 쓴다. 두
구성은 설정 한 줄로 전환된다.
