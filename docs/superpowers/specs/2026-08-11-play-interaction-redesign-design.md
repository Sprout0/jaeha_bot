# 놀이 상호작용 개조 — 확장·모방·완성형 (설계)

> 작성일: 2026-08-11 · 대상: `app/education_modes.py` 중심
> 근거 문서: `jaeha_bot_docs/docs/리서치_유아_대화기법_놀이설계.md` (2026-08-11)

## 1. 문제

목적은 **아이가 실제로 더 말하게 하는 것**이다. 문헌에서 효과크기가 가장 큰 개입은
**확장(expansion)과 모방(imitation)** 인데(recast 메타분석 0.76~0.96 SD), 지금 봇은
놀이 중에 둘 다 하지 않는다. 구조적으로 불가능하기 때문이다:

```python
close = self._is_close(tgt, text)                          # 맞았나 여부만 뽑고
return self._react_next_beat(subj, tgt, close, nsubj, ntgt)  # 아이 말은 버려진다
```

놀이 중 LLM 은 `agent.render(instruction)` 으로만 불리고 stateless 다. 상태머신이 만든
지시 문자열에 아이 말이 없으면 **LLM 은 확장할 재료 자체가 없다.**

추가로 2세에게는 wh- 질문("어떻게 울어?")보다 **완성형**("강아지는 멍…?")이 맞는데
지금은 전부 wh- 다. 완성형은 정답을 정확히 받아쓸 필요가 없어 **우리 STT 약점과도 궁합이 좋다.**

## 2. 범위

**바꾼다**
- `app/education_modes.py` — beat 인터페이스, 확장·모방 문구, 완성형, 재시도 상태
- `scenarios/scenario_cards.json` — `sound_match` 카드에 `lead` 필드
- `app/metrics.py` + `app/main.py` — 계측 2필드
- `configs/prompt_templates.yaml`, `data/finetune_seed.jsonl` — 자유 대화용

**안 건드린다** (한 번에 변수 두 개를 바꾸지 않는다)
- 배치 크기·"더 할래?" 체크포인트·"그만" 종료
- `match_trigger`(2026-08-10 수정분)
- 자모거리 임계 0.5
- 놀이 개수 — 새 놀이는 이 틀이 검증된 뒤

## 3. 설계

### 3-1. `close: bool` → `said: str | None`

`None` 이 곧 "못 알아들음"이라 별도 불리언이 필요 없다. 값 하나로 **맞았는지 +
무엇으로 인정했는지**를 함께 나른다.

### 3-2. `_heard()` — 오인식 차단 (핵심)

```python
def _heard(self, target: str, text: str) -> str | None:
    """얼추 맞으면 **정답 낱말**을 돌려준다. 아이 발화 원문은 밖으로 내보내지 않는다."""
    return target if jamo_ratio(_norm(text), _norm(target)) <= 0.5 else None
```

🔴 **아이 발화 원문을 되받으면 오인식이 증폭된다.** 아이가 "멍멍" 했는데 STT 가 "명명"
으로 받아쓰면 봇이 "명명! 강아지가 명명 해!" 라고 말한다. 카드의 기대 어휘로 정규화해
되받으면 이 사고가 구조적으로 불가능하다. 기존 '제한 어휘 priming' 방침과 같은 결이다.

### 3-3. 확장 + `require` 강제

```python
def _react_next_beat(self, animal, sound, said, nanimal, nsound):
    if said:
        fb  = f"{said}! {_j(animal)} {said} 하고 울어! 그럼 {_j(nanimal)}?"
        ins = (f"아이가 '{said}' 라고 말했어. 그 말을 먼저 그대로 따라 하고, "
               f"'{_j(animal)} {said} 하고 울어' 처럼 한두 낱말만 붙여 늘려줘. "
               f"그다음 '{_j(nanimal)}?' 하고 이어. 반말 두 문장.")
        return _beat(fb, ins, [said, nanimal])
```

`require` 에 `said` 를 넣으면 LLM 이 아이 말을 빠뜨렸을 때 검증에 걸려 템플릿으로
폴백되고, 템플릿은 확장을 반드시 한다. → **확장이 LLM 의 선의가 아니라 구조로 보장된다.**
(2026-08-07 안전 규칙에서 쓴 방식과 같다: 규칙을 주면 지키고 안 주면 실패한다.)

⚠️ 확장은 **한두 낱말만** 늘린다(아이 수준 +1 원칙). 문장을 통째로 갈아치우면 모델이 안 된다.

### 3-4. 완성형 프롬프트 — 카드의 `lead`

```json
{"sound": "멍멍",     "answer": "강아지",  "lead": "멍"}     → "강아지는 멍…?"
{"sound": "삐약삐약", "answer": "병아리",  "lead": "삐약"}   → "병아리는 삐약…?"
{"sound": "음메",     "answer": "소"}                        → "소는 어떻게 울어?"
```

`lead` 가 있으면 완성형, 없으면 기존 wh-. **비율을 JSON 에서 조절**하니 코드를 안 건드리고
실험할 수 있고, "음메"→"음" 같은 어색한 건 안 넣으면 그만이다.

전부 완성형으로 만들지 않는다 — 문헌은 완성형을 "1~2세에 가장 적합한 유형"이라 했지
유일한 유형이라 하지 않았고, 한 형태만 반복하면 단조롭다.

**`repeat_word` 에는 `lead` 를 넣지 않는다.** 따라 말하기는 설계상 이미 모방 놀이이고,
모방 자체가 문헌이 꼽는 최상위 기법이다. 굳이 완성형으로 바꿀 이유가 없다.

**로딩:** `ITEMS` 는 `(대상, 기대값)` 2-튜플이고 `match_trigger` 가
`[a for a, _ in ANIMAL_ITEMS]` 로 푼다. 3-튜플로 바꾸면 그게 깨진다.
→ 별도 모듈 상수 `_LEADS: dict[str, str]`(기대값 → lead)로 싣는다. 기존 자료구조 무변경.

### 3-5. 재시도 — "같이 해보자" 한 번

못 알아들었을 때 **같은 항목에 한 번 더 머문다.** 2세가 실제로 소리를 낼 계기를 준다.

```python
# await_answer 안
said = self._heard(tgt, text)
if said is None and not self.retried:
    self.retried = True
    return self._retry_beat(subj, tgt)      # "강아지는 멍멍! 같이 해보자, 멍멍!"
self.retried = False
self.bi += 1
... (이하 기존과 동일)
```

- 상태 변수 `retried: bool` 하나 추가. `__init__` 과 `_next_batch()` 에서 False 로 초기화.
- **기회는 정확히 한 번.** 두 번째에는 맞든 틀리든 다음 항목으로 넘어간다(무한 루프 방지).
- 두 번째에 맞히면 정상 확장 경로를 탄다.
- "그만" 은 `step()` 맨 위에서 처리되므로 재시도 중에도 즉시 빠져나간다.

대가: **배치의 항목 수는 그대로지만 턴 수가 최대 두 배**가 될 수 있다(4항목 → 최대 8턴).
"더 할래?" 체크포인트가 그걸 받아낸다.

### 3-6. 계측 — 게임과 결합하지 않는다

`main.py` 의 `metrics.record_turn(...)` 에 `child_text=text` 하나만 추가하고,
`metrics.py` 가 계산한다:

| 필드 | 정의 | 목표 |
|---|---|---|
| `expansion_delta` | 봇 답변 낱말수 − 아이 발화 낱말수 | +1~2 |
| `reuse` | 아이 낱말 중 봇 답변에 다시 나온 비율 | 높을수록 좋음 |

놀이·자유대화 양쪽에 붙고 `GameManager` 와 결합이 없다.

⚠️ **둘 다 대리지표다.** "아이가 실제로 더 말했는가"는 재지 못한다. 안전 판정기를
하한선으로 읽기로 한 것과 같은 태도가 필요하다. 대상 아이가 아직 없으므로
**지금은 배선만 해두고 숫자로 판단하지 않는다.**

### 3-7. 자유 대화 — 프롬프트·few-shot

- `prompt_templates.yaml`: 대화기법 블록을 **금지 목록과 분리해 앞쪽에** 신설
  (확장 / 아이 낱말 재사용 / 완성형 / 한 번에 하나)
- `finetune_seed.jsonl`: 확장 few-shot 5~8쌍.
  메모리 기록 — *"답변 길이는 프롬프트 문구가 아니라 few-shot 예시 길이를 따라간다"*
- `recovery`: `"음, 다시 한 번 말해줄래?"` → 재시도 요구 대신 모델링으로 이어가는 문구

## 4. 테스트 (TDD, RED 먼저)

| # | 무엇을 지키나 | 깨지면 나는 증상 |
|---|---|---|
| 1 | 🔴 오인식 원문이 확장에 안 들어간다 (아이 "명명" → 답변에 "명명" 없고 "멍멍" 있음) | 봇이 잘못된 발음을 가르친다 |
| 2 | 확장 폭이 +1~2 낱말 | 아이 수준을 넘겨 모델이 안 됨 |
| 3 | `lead` 있으면 완성형, 없으면 wh- | 완성형이 조용히 사라짐 |
| 4 | LLM 이 `said` 를 빠뜨리면 템플릿 폴백 | 확장 보장이 무너짐 |
| 5 | 재시도는 정확히 한 번, 두 번째엔 진행 | 같은 항목에 갇힘 |
| 6 | 재시도 중 "그만" 이 즉시 먹힘 | 탈출 불가(2026-08-10 에 겪은 종류) |
| 7 | 기존 배치·체크포인트·종료 회귀 없음 | 놀이 흐름 붕괴 |

마이크·모델 없이 도는 테스트로 만든다(기존 놀이 테스트와 동일 방식).

⚠️ **검사 대상은 `fallback` 템플릿과 `instruction`·`require` 문자열이다.** LLM 출력은
오프라인에서 재현되지 않으므로 테스트하지 않는다. 확장이 보장되는 근거도 거기에 있다 —
LLM 이 어떻게 답하든 `require` 검증에 걸리면 템플릿으로 내려오고, **템플릿은 결정적이다.**

## 5. 안 하는 것 (YAGNI)

- 새 놀이 추가 — 이 틀이 검증된 뒤
- 비전 놀이(색칠·사물찾기) — 껍데기 그대로 둔다
- 자모거리 임계 튜닝 — 한 번에 하나만 바꾼다
- 인정률(성공률) 계측 — 잴 아이가 없다
- A/B 구조 — 비교할 대상이 없다

## 6. 열린 항목

- **효과 검증 불가.** 대상 아이가 아직 없어 "발화가 늘었는가"를 측정할 수 없다.
  이 설계는 **문헌 근거로 방어**하고 계측만 준비해 둔다.
- `silence_duration: 1.2` 는 2세가 문장 중간에 뜸 들이면 자른다. 실제 3세 녹음 때
  **올리는 방향**으로 재조정(이 스펙 범위 밖).
