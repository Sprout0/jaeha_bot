## 3. ① 놀이 이탈 — 흘려보내며 바로잡기

### 3.1 놀이 문장을 두 조각으로
놀이 비트(`education_modes._beat`)에 두 필드를 더한다. 둘 다 **아이 말을 되받지 않는 정해진 문장**이라 미리 녹음할 수 있다.

| 필드 | 뜻 | 동물 소리 놀이 예 | 따라 말하기 예 |
|---|---|---|---|
| `fix_react` | 첫 문장(반응)을 대신할 말 | `강아지는 멍멍 하고 울어!` | `사과, 잘했어!` |
| `fix_next` | 둘째 문장(다음 질문·권유)을 대신할 말 | `그럼 고양이는 어떻게 울어?` / `더 할래?` / `같이 해보자, 멍멍!` | `이번엔 바나나!` / `더 할래?` |
| `allow` | 이 턴에 나와도 되는 놀이 이름 | 지금 동물·다음 동물 | 지금 낱말·다음 낱말 |

- 조각 문장은 놀이 카드(동물 8, 낱말 10)에서 **전부 뽑아** 기동 때 고정 문구 캐시로 만든다(약 40개, 첫 기동에만 2~3분, `VoiceCache` 가 이미 있는 건 건너뛴다).
- 시작 턴(`_intro_beat`)은 반응 자리에 `좋아, 동물 소리 놀이 하자!` / `따라 말하기 놀이 하자!` 를 쓴다.

### 3.2 흐름
1. 놀이 턴은 지금처럼 **바로 흘려보낸다**(붙잡지 않는다).
2. 글자가 들어올 때마다 본다: 놀이 카드의 이름 중 `allow` 에 **없는 이름**이 나오면 → **이탈**.
   - 그 이름의 글자 위치를 소리 위치로 옮기고(글자 비율), 그 바로 **앞의 조용한 틈**(에너지가 가장 낮은 30ms, 앞쪽 0.4s 안)에서 자른다.
   - 자른 곳이 첫 문장 안이면 `fix_react` + `fix_next`, 둘째 문장이면 `fix_next` 만 이어 붙인다.
   - 이후 오는 소리·글자는 버린다. `response.cancel` 을 보낸다.
3. 글자가 끝났는데(`response.done`) **다음 질문의 필수 낱말이 없으면**(`require` 중 다음 이름·질문 꼴) → 둘째 문장 앞의 조용한 틈에서 자르고 `fix_next` 를 붙인다. 이 판정은 요청 뒤 0.6~0.9s 에 나고 둘째 문장은 그보다 한참 뒤에 들린다.
4. 자를 곳이 **이미 스피커로 나갔으면**(늦음) 그냥 지금 대기열을 비우고 조각을 붙인다. 계측에 `leaked` 로 남긴다.
5. 대화 기록(history)에는 **실제로 나간 말**(자른 앞부분 + 조각 문장)을 남긴다.
6. 부모 기록에는 남기지 않는다(위험이 아니다). 로그·계측(`game_fixed`, `game_leaked`)에만.

### 3.3 스피커에 필요한 것
`StreamSpeaker` 에 두 가지를 더한다(가짜 스피커도 같이).
- `mark()` → 이 턴 소리의 시작점. `played()` → 그 뒤로 실제로 낸 샘플 수(재생 콜백에서 센다).
- `truncate(keep)` → 그 턴 시작점 기준 `keep` 샘플 뒤의 대기열을 버린다.
- 대화 구간은 이 턴에 받은 소리를 이어 붙여 **복사본**을 들고 있다(조용한 틈 찾기용). 한 턴 소리는 5초 안팎 = 12만 샘플이라 부담 없다.

## 4. ② 짧은 명령 — 힌트 + 모델 도구

### 4.1 받아 적기 힌트
`song_names.transcribe_prompt()` 에 명령 낱말을 더한다: `잘 자, 바이바이, 그만할래, 쉬고 있어, 동물 소리 놀이, 따라 말하기 놀이, 노래 틀어줘`. (노래 이름은 그대로.)

### 4.2 모델 도구
- `session.update` 에 도구 셋을 싣는다.

| 도구 | 인자 | 봇이 하는 일(기존 경로) |
|---|---|---|
| `go_to_sleep` | 없음 | 잠들기 문구 → 대기 |
| `play_song` | `title: str`(비면 동요) | `music.handle(f"{title} 틀어줘")` → 노래 안내·재생·대기 |
| `start_game` | `kind: "animal" \| "repeat"` | `games.maybe_start_beat("동물 소리 놀이 하자" / "따라 말하기 놀이 하자")` → 놀이 시작 턴 |

- **글자 판단이 `chat` 인 턴에만** `tool_choice: "auto"`. 놀이·노래·그대로 읽기 턴은 `tool_choice: "none"` — 이미 할 일이 정해졌다.
- 모델이 도구를 부르면(`response.done` 의 출력에 `function_call`): 대화에 `function_call_output`(`"ok"`)을 넣어 짝을 맞추고, 위 기존 경로를 탄다. 노래·놀이는 새 요청이 한 번 더 나간다.
- 노래 기능이 꺼져 있으면 `play_song` 을 싣지 않는다.
- 도구 설명에 **언제 부르지 말지**를 적는다: 인형·동물에게 "잘 자"라고 하는 놀이 중 말, 노래 **이야기**(틀어 달라는 게 아닌 것).
- 계측에 `tool` 필드(부른 도구 이름 또는 null).

### 4.3 위험
- 아이가 인형에게 "잘 자"라고 해도 봇이 잘 수 있다 → 사람 목소리 실기에서 본다.
- 도구 호출 턴은 한 번 더 요청하므로 노래·놀이 시작이 **0.6~0.9s 더 걸린다**(글자로 알아들은 경우는 그대로).

## 5. ③ 말 끝 — 재기

### 5.1 도구 `tools/turn_end_probe.py`
- 입력: `reports/stt/young/manifest.jsonl`(3~6세 153발화, 노트북에 전부 있음).
- 발화마다: 앞 무음을 잘라 **실제 말 끝**을 안다(`realtime_probe.load_pcm(trim="speech")` 와 같은 기준) → 실시간 속도로 흘리고 뒤에 무음 4초 → 서버 이벤트(`speech_started/stopped`, `audio_end_ms`)를 받는다. 답은 요청하지 않는다(`create_response: false`, 받아 적기 끔 — 싸다).
- 방식: `server_vad` 1200 / 900 / 600ms, `semantic_vad` eagerness `low` / `medium` / `high`.
- 잰다:
  - **빨라짐:** 실제 말 끝을 보낸 시각 → `speech_stopped` 도착(중앙·p90).
  - **잘림:** 실제 말 끝보다 **0.1s 넘게 먼저** 첫 `speech_stopped` 가 온 발화의 비율(= 말 중간에 끝났다고 판단).
- 결과: `reports/turn/realtime_turn_end.md`(표) + 원자료 jsonl(저장소 제외, 기존 `reports/turn` 원칙).
- 비용: 입력 소리만, 153 × 6 ≈ 918회 × 약 3초 → 약 $1~2(추정, 실행 전에 첫 10개로 확인).

### 5.2 결정
표를 보고 사용자가 고른다. 고른 값은 `realtime.silence_ms` 또는 새 `realtime.turn_detection` 설정 한 줄로 바꾼다(그 코드는 이 문서의 범위가 아니다 — 고른 뒤 작게 붙인다).

## 6. 오류 처리

| 상황 | 동작 |
|---|---|
| 조각 문장 캐시가 없다 | 경고. 자르기는 하고 이어 붙이기만 건너뛴다(틀린 말이 안 나가는 게 우선) |
| 조용한 틈을 못 찾음 | 틀린 이름 바로 앞 위치에서 그냥 자른다 |
| 도구 인자 파싱 실패·모르는 도구 | 경고, 일반 대화로 둔다(모델이 소리로 답하지 않았으면 `recovery` 문구) |
| 도구 호출 뒤 요청 실패(끊김) | 가드 설계의 다시 붙기 경로 |

## 7. 시험

### 자동
- `education_modes`: 모든 비트에 `fix_react`/`fix_next`/`allow` 가 있고, 조각 문장 전체 목록 함수가 카드와 맞는다.
- 이탈 판정(순수 함수): 허용 이름만 → 없음 / 다른 동물 → 위치 / 질문 빠짐 → 둘째 문장 경계.
- 조용한 틈 찾기(순수 함수): 합성 소리(말-무음-말)에서 무음 안을 고른다.
- `Conversation`: 흘려보내는 놀이 턴에서 다른 동물 글자 → `truncate` 호출 + 조각 문장 + `response.cancel` / 질문 빠짐 → done 에서 `fix_next` / 정상 → 아무것도 안 함 / history 는 나간 말.
- 도구: `chat` 턴 요청에 `tool_choice: auto`, 놀이·노래 턴은 `none` / `function_call` `go_to_sleep` → 잠들기 / `play_song` → 노래 경로 / `start_game` → 놀이 시작 / `function_call_output` 을 보낸다.
- `turn_end_probe`: 이벤트 목록 → 빨라짐·잘림 계산(순수 함수).

### 실서버 (노트북)
- 놀이 8턴 이상 돌려 이탈이 났을 때 자른 위치와 이어 붙인 결과를 로그로 확인(09-21 `drift_lead.py` 확장).
- 합성 "탈자"·"잘 자" 발화로 도구 호출 여부.
- `turn_end_probe` 전체 실행 → 표.

### 젯슨 실기(사람)
- 동물 소리 놀이 한 판, "잘 자" 여러 번(인형에게 하는 말 포함), 노래 이름 말하기.

#### 2026-09-22 노트북 실서버 — 명령 도구 (글자 13개, chat 으로 떨어지는 말)

- 첫 판: 도구를 부른 게 1/5. 노래 규칙이 "'곰 세 마리 틀어줘, 처럼 말해 줘!'라고 알려준다"를 시켜서, 모델이 도구 대신 **명령어를 가르쳤다**.
- 도구가 켜지면 노래 규칙을 "play_song 을 부른다"로 바꾸고 잠들기·놀이 규칙을 더했다(e53d5eb) → **11/13**.

- ⚠️ 이 확인은 **글자 입력**이다. '소리를 직접 들어 탈자를 잘 자로 알아듣는가'는 사람 목소리 실기에서만 볼 수 있다.
