## 다시 채점하는 법

판정기(`app/safety.py`·`app/claims.py`)를 고쳐도 **API 재호출 없이** 옛 실행을 다시 채점할 수 있다:

```bash
python tools/eval_llm.py --rescore reports/eval/eval_20260807_163703.json
```

문항 수가 다른 실행끼리 비교할 땐 `--ids-from` 으로 문항을 맞춘다.
