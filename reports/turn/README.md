# 턴 종료 판정 (Smart Turn v3.2) 채점 결과 — 2026-08-24

> **결론: 기각.** 성인에서 98% 맞히는 모델이 우리 아이 음성(3\~6세)에서 37% 다.
> 말끊김을 5% 이하로 묶으면 얻는 시간은 **0.05초**, 즉 쓸 수 없다.
>
> 이 파일은 **보고서가 인용할 요약**이다. 원자료(`young_v32*.json`)는 저장소에서 제외한다
> — 아래 '원자료를 안 넣는 이유' 참조. 표의 모든 수치는 2026-09-12 에 원자료로 재계산해
> 확인했다.

## 무엇을 재려 했나

체감 응답 4.14초의 내역에서 **VAD 꼬리 1.2초**는 정의상 무음이다. 말이 끝난 걸 아는
방법이 "1.2초 조용한지 세기"뿐이라 그렇다. Smart Turn 은 오디오만 보고 '이 말이 끝났나'를
판정한다. 맞힌다면 꼬리를 0.2초로 줄여 **−1.0초**를 번다.

두 값을 따로 재야 한다. 하나만 보면 속는다.

- **재현율** = 진짜 끝났을 때 '끝났다'고 하는 비율 → 높아야 시간을 번다
- **오탐률** = 아직 말하는 중인데 '끝났다'고 하는 비율 → 높으면 **아이 말을 끊는다**

아이에게는 오탐이 훨씬 비싸다. 말 끊긴 아이는 다시 말하지 않는다.

## 도구를 먼저 검증했다 (음수 결과를 믿을 근거)

우리 숫자가 나쁘게 나왔을 때 제일 먼저 의심할 것은 우리 코드다. 그래서 **벤더 데이터 +
벤더 라벨**로 도구를 먼저 채점했다.

| | 정확도 | 재현율 | 오탐률 |
|---|---|---|---|
| 우리 도구 (벤더 데이터·라벨) | 99.38% | 100.00% | 1.45% |
| 벤더 공개치 (한국어 889개) | 96.96% | 98.40% | 2.25% |

공개치를 넘어서므로 전처리가 맞다. 공식 `inference.py` · `audio_utils.py` 와 대조했다 —
8초 창의 **앞쪽**에 0 을 채운다(뒤에 채우면 모델이 보는 마지막 순간이 무음이 돼 판정이
통째로 뒤틀린다).

## 핵심 결과 — 같은 코드 경로, 성인 vs 아이

| 표본 | n | 재현율 (문턱 0.5, 무음 0.2초) |
|---|---|---|
| 벤더 한국어 **성인** | 160 | **97.80%** |
| AI-Hub 3\~6세 (`_young`) | 153 | **37.25%** |

60%p 차이다. 이 한 줄이 보고서 1장의 근거이고, "성인용 부품을 아이에게 그대로 쓰면
무너진다"를 추정이 아니라 **재현 실험**으로 보인 것이다.

## 무음 길이를 바꿔도 안 된다 (아이 153개, 문턱 0.5)

미완 표본은 말소리 구간의 40/60/80% 지점에서 자른 것이다. 완결·미완 **양쪽에 같은 길이의
무음**을 붙였다.

| 붙인 무음 | 재현율 (완결) | 오탐률 40% 지점 | 60% | 80% |
|---|---|---|---|---|
| 0.2초 | 37.3% | 58.8% | 49.0% | 44.4% |
| 0.4초 | 47.7% | 79.7% | 70.6% | 69.9% |
| 0.6초 | 54.2% | 83.7% | 77.8% | 77.8% |
| 0.8초 | 52.9% | 81.7% | 83.7% | 76.5% |
| 1.0초 | 57.5% | 88.2% | 84.3% | 73.2% |

무음을 늘리면 재현율은 오르지만 **오탐이 더 빨리 오른다.** 말 중간에 쉬는 아이에게
"조용하니 끝났다"고 답하는 것이므로 방향이 뒤집힐 수 없다.

0.2초에서만 상한을 지킬 문턱이 있고, 거기서 버는 시간이 0.05초다. **기각의 근거가 이 표다.**

## 디지털 0 이 원인일까 — 아니다 (`--pad room`)

붙이는 무음이 완전한 0 이라 모델의 학습 분포 밖일 가능성을 의심해, 같은 녹음의 룸톤으로
다시 붙여 채점했다.

| 붙인 무음 | 재현율 (0 패딩) | 재현율 (룸톤) |
|---|---|---|
| 0.2초 | 37.3% | 37.3% |
| 0.4초 | 47.7% | 47.1% |
| 0.6초 | 54.2% | 53.6% |
| 1.0초 | 57.5% | 56.9% |

차이가 없다. 무음의 종류가 아니라 **아이 발화 자체**가 원인이다.

## 🟢 부산물 — 아이 발화의 내부 쉼 (이게 더 오래 쓰인다)

153개 발화 / 496 구간: **중앙 0.080초 · p90 0.320초.**

모델 없이 고정 꼬리만 1.2 → 0.9초로 줄여도 **−0.30초**이고, 말끊김은 2.0 → 5.2% 다.
Smart Turn 이 기각돼도 이 값은 남는다.

⚠️ AI-Hub **낭독체** 기준이다. 실기 자유대화에서 다시 확인해야 한다.

## 🔴 이 두 가지를 안 하면 숫자가 통째로 거짓이 된다

1. **완결·미완 표본의 뒤 무음을 맞춰야 한다.** 이 모델은 무음 길이를 크게 참고한다
   (아이 30개: 0.0초 → 0.187, 0.4초 → 0.366, 0.8초 → 0.765). 안 맞추면 '말이 끝나게
   들리나'가 아니라 **'무음이 기냐'**를 재게 된다. 첫 실험이 이걸로 통째로 틀렸다.
2. **미완 표본은 말소리 구간 기준으로 잘라야 한다.** 파일 길이 기준으로 자르면 뒤 무음이
   긴 녹음에서 이미 끝난 지점을 잘라, '미완'이 실은 완결이 된다.

```bash
  --pad room --json reports/turn/young_v32_room.json
```
