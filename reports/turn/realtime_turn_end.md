# 전면 API 말 끝 판정 방식 비교 — 아이 녹음 153개, 실서버 (2026-09-22)

> 도구: `tools/turn_end_probe.py` · spec: `docs/superpowers/specs/2026-09-22-realtime-turn-fixes-design.md` §5
> 원자료(`realtime_turn_end.json`, 918줄)는 저장소에 넣지 않는다 — 도구로 다시 만든다.

## 무엇을 쟀나

AI-Hub 3~6세 자유대화 153발화(`reports/stt/young/manifest.jsonl`)를 말소리 끝에서 자르고,
실시간 속도로 OpenAI Realtime(gpt-realtime-mini)에 흘린 뒤 무음 6초를 더 보냈다. 답은 만들지 않았다.

- **빨라짐** = 실제 말 끝을 보낸 순간 → 서버가 "말 끝났다"(`speech_stopped`)를 보낸 순간
- **잘림** = 실제 말 끝보다 0.1초 넘게 **먼저** "끝났다"가 온 발화 = 아이가 아직 말하는데 봇이 답을 시작했을 발화
- 방식 6개를 동시에 돌렸다. 보내는 속도는 벽시계로 맞췄다 — 무음 구간 밀림 최대 0.031초.

## 결과

| 방식 | 빨라짐 중앙 | p90 | 잘림 | 판정 없음 |
|---|---|---|---|---|
| **server_vad 1200ms (지금)** | 1.44s | 1.49s | 3/153 = 2% | 0 |
| server_vad 900ms | 1.16s | 1.19s | 5/153 = 3% | 0 |
| server_vad 600ms | 0.84s | 0.88s | 8/153 = 5% | 0 |
| semantic_vad low | 0.72s | 0.91s | 9/153 = 6% | **3** |
| semantic_vad medium | 0.84s | 1.16s | 6/153 = 4% | 0 |
| semantic_vad high | 0.84s | 1.02s | 7/153 = 5% | 0 |

## 읽는 법

- 지금 방식(1.2s)도 서버 처리까지 **1.44s** 가 걸린다 — 젯슨 실기의 대기 1.36~1.7s 와 맞는다.
- 줄이는 만큼 잘림이 는다. 가장 싼 교환은 **900ms: −0.28s 에 잘림 +1%p**(2→3%).
- semantic_vad 는 **중앙은 빠르지만 들쭉날쭉하다**(medium p90 1.16s). low 는 3발화에서 6초 안에 끝을 **못 정했다** — 실기라면 봇이 대답을 안 한다.
- 잘린 발화는 방식과 상관없이 **같은 몇 개**가 반복된다(6.6s·8.2s·8.5s 짜리 긴 발화, 3~4세). 긴 말 중간에 오래 쉬는 아이다.
- 성인용 끝 감지(Smart Turn)가 아이에서 37% 로 무너진 것(08-24, `README.md`)과 달리, semantic_vad 는 아이에서도 잘림 4~6% 로 **쓸 수는 있는** 수준이다. 다만 900ms 보다 나은 교환은 아니다.

## 한계

- 합성음이 아니라 실제 아이 녹음이지만, **녹음된 문장 하나씩**이다. 실제 대화의 '말하다 멈추고 생각하기'는 더 길 수 있다.
- 잘림은 '서버가 끝났다고 한 순간'이지, 아이가 실제로 말을 멈췄는지(끊겼는지)가 아니다 — 봇이 답을 시작하면 아이 말은 반이중이라 버려진다.
